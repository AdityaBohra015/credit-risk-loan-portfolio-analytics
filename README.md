# Credit Risk & Loan Portfolio Analytics

## Project Overview

I analyzed loan portfolio data to understand borrower default patterns and identify characteristics associated with higher default risk.

Using SQL, Python, and Tableau, I explored loan purposes, income levels, loan-to-income ratios, and employment history to uncover insights that could support better lending decisions.

## Key Findings

- **32,411 loans** analyzed after data cleaning.
- **7,089 defaults** recorded, representing an overall default rate of 21.87%.
- **Debt consolidation** had the highest default rate at 28.68%.
- **Medical loans** contributed the largest number of defaults, with 1,617.
- Higher loan-to-income ratios were associated with substantially higher default rates.

## Tools Used

- Python (Pandas)
- SQL (MySQL)
- Tableau

## Dashboards

1. **Risk Overview** — Portfolio size, default rate, and loan-purpose risk.
2. **Borrower Risk Analysis** — Default patterns across borrower and loan characteristics.
3. **Recommendations & Business Impact** — Practical actions based on the analysis.

## Business Recommendations

- Review repayment capacity when loan amounts are high relative to annual income.
- Investigate loan categories with higher default rates or larger default volumes.
- Consider employment history alongside other borrower characteristics.

## Limitations

The dataset is a sample and may not represent an actual bank portfolio. The analysis identifies relationships, not causes of default. Some missing employment data was filled during cleaning, and results for small groups should be interpreted cautiously.
